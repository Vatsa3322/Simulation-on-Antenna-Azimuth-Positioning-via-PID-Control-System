# Simulation-on-Antenna-Azimuth-Positioning-via-PID-Control-System
The azimuth angle is the horizontal angle that represents the direction of an object measured in the plane parallel to the Earth’s surface. It is typically measured clockwise from a reference direction, usually true north, and ranges from 0° to 360°.

In antenna systems, the azimuth angle determines the horizontal pointing direction of the antenna. Accurate azimuth control is critical in applications such as satellite communication, radar tracking, and wireless links, where precise alignment directly affects signal strength and system performance. This project focuses on modeling and controlling the antenna azimuth angle using feedback control techniques to achieve fast, stable, and accurate positioning.
